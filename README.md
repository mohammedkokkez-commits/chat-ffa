# محادثة خاصة (مباشرة، متوافقة مع آيباد الجيل الأول)

محادثة بين شخصين فقط:

- تسجيل دخول باسم مستخدم وكلمة مرور
- الرسائل تصل فورًا بدون تحديث الصفحة (Long Polling)
- الرسائل تُحذف تلقائيًا بعد 5 دقائق من الجهازين معًا
- زر "حذف المحادثة" يمسحها من الجهازين في اللحظة نفسها
- بدون أي مكتبات خارجية، ولا تُحفظ الرسائل على قرص أو قاعدة بيانات

## متغيرات البيئة

| المتغير | الوصف |
| --- | --- |
| `USER1_NAME` | اسم المستخدم الأول |
| `USER1_PASSWORD` | كلمة مرور المستخدم الأول |
| `USER2_NAME` | اسم المستخدم الثاني |
| `USER2_PASSWORD` | كلمة مرور المستخدم الثاني |
| `COOKIE_SECRET` | نص عشوائي طويل (32 حرفًا على الأقل) لتوقيع الجلسات |
| `TTL_MINUTES` | اختياري: مدة بقاء الرسالة بالدقائق (الافتراضي 5) |
| `PORT` | اختياري: المنفذ (الافتراضي 3000) |

## التشغيل على شبكة البيت (HTTP)

```bash
export USER1_NAME=ali USER1_PASSWORD=كلمة_سر_1
export USER2_NAME=sara USER2_PASSWORD=كلمة_سر_2
export COOKIE_SECRET=اكتب_هنا_نصا_عشوائيا_طويلا_من_32_حرفا_او_اكثر
npm start
```

ثم افتح من الآيباد `http://عنوان-الجهاز:3000` على نفس الواي فاي.

## النشر على Render

1. ارفع الملفات على GitHub.
2. New → Web Service، واختر المستودع.
3. Build Command: `npm install`
4. Start Command: `npm start`
5. أضف متغيرات البيئة من تبويب Environment.
6. Deploy.

ملاحظة: Render يعمل بـHTTPS فقط، وآيباد iOS 5.1.1 قد يعجز عن فتح مواقع HTTPS الحديثة. إذا حدث ذلك فشغّل المشروع على شبكة البيت.
